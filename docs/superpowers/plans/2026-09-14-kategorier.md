# Kategorisider: farve, produktbilleder og vejledning

**Mål:** Finpuds iPhones, iPads, bærbare, ure og smartphones inden brugerens gennemgang og senere drøftelse af implementering.

**Retning:** Bevar det godkendte udtryk, eksisterende filtre, data og SEO. Giv de fem kategorier lyse, afdæmpede baggrunde og ægte produktfotos. Indsæt garanti og tilbehør som almindelige gridfelter på iPhones og iPads. Den nuværende phonespot.dk/iphones er reference for placering, ikke for gamle pristilbud eller produktpåstande.

**Rammer:** Arbejd lokalt på eksisterende featurebranch. Ingen produktion, betaling, fragt, databaser eller katalogændringer. DM Sans til UI; mørkegrøn #1A3D2E, creme og afdæmpede farver. Alt på dansk. 36 måneders garanti gælder enheder. Metadata, FAQ og interne links bevares.
